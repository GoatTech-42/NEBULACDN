NEBULA CDN - Astray package: third-party notices
================================================
Package: games/astray.html + games/assets/astray.*  (derivative of https://github.com/wwwtyro/Astray, last upstream commit 2022-08-13)
Changes from upstream: the four texture images are not shipped. brick and floor use CC0 textures downscaled to 256x256 JPEG and inlined; the ball texture is generated at runtime; scripts are loaded through a status-checking joiner that shows a visible error if a file fails to load; onResize now returns early before the game is initialised (upstream threw a TypeError on an early resize event); Three.js is split into two byte-exact halves (three0 + three1 = the original file); KeyboardJS is replaced by a small original binder (astray.keyboard.js). Box2dWeb, Three.js r49, jQuery 1.7.2, maze.js are unmodified.
